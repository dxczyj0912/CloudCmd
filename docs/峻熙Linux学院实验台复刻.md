3. **步骤级打卡**：执行某一步的命令即自动打勾（命令归一化后前缀匹配），**全部步骤完成才显示「已打卡」**并展开讲解。

### 4.2 为复刻页给 shell 引擎加的能力

复刻页那台机器是 **Rocky Linux 9 / ens160 / 192.168.17.10 / 网关 192.168.17.1**，和主站默认环境（EulerOS / eth0 / 10.0.1.23）不同。为此给引擎加了**实例级环境覆盖**：

```js
// 复刻页声明自己那台机器的身份；主站不传，用默认环境
var shell = window.CC_SHELL.create({
  hostname: 'jx-rocky-lab01', ip: '192.168.17.10', gateway: '192.168.17.1',
  dns: ['114.114.114.114', '223.5.5.5'],
  nic: { name: 'ens160', mac: '00:0c:29:8f:3a:21', cidr: '192.168.17.10/24', brd: '192.168.17.255' }
});
```

- `hostname` / `ip addr` / `netstat -rn` / `nmcli` 全部读这份环境，因此 `ip addr` 会显示 `ens160 + 192.168.17.10`，`netstat -rn` 的网关是 `192.168.17.1`。
- 每个实例克隆一份环境，**实例之间互不污染**（主站仍是 web-prod-01 / eth0 / 10.0.1.23）。
- 顺带补齐了教材里常用、原先缺的命令：**`host`**（canonical name 链）、**`netstat -rn`**（路由表）、**`nmcli`**（device/con 子命令）、**`nmtui`**（说明无法模拟并给等价命令）。
- IPv6 link-local 地址由 MAC 按 EUI-64 推导，不再写死。
