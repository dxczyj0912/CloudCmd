# 03B · 私有对象存储、版本与恢复

前置：[云账号与成本边界](00-云账号与成本边界.md)。本项目使用**新建测试桶**，演练对象上传、私有访问、短时分享、版本恢复和删除。腾讯云对应产品为 [COS](https://cloud.tencent.com/document/product/436)；不同厂商可按同样验收目标使用 S3 兼容服务。

## 逐步操作

1. 在实验区域新建一个名称唯一的测试桶，默认权限选**私有读写**，记录桶名、区域、计费方式和预计清理时间。不要把包含真实个人进度或凭证的文件上传。
2. 在本机创建一个仅含 `cloudcmd-lab-v1` 的文本文件，计算 SHA-256；上传为 `lab/readme.txt`，在控制台核对对象大小和摘要或 ETag 的含义。注意：分片上传时 ETag 不一定等于文件 MD5。
3. 用未登录浏览器直接访问对象链接，应被拒绝。使用控制台生成**短时有效**的签名下载链接，在到期前下载并比较本机 SHA-256；到期后验证链接失效。
4. 启用版本控制，把本地文件改为 `cloudcmd-lab-v2` 并覆盖上传。列出两个版本，下载旧版本并比较其 SHA-256；再将旧版本恢复为当前版本，证明操作可逆。
5. 查看生命周期配置：为 `lab/` 前缀设置短期测试规则，记录规则开始生效时间；不要假定配置后立即删除。实验结束时主动删除**所有版本和删除标记**，核对桶为空后再删除桶。

## 验收

### 逐步命令与检查点（本机 PowerShell）

控制台按第 1 步新建**私有**测试桶，记下桶名、区域和对象 URL；下列文件只含测试文本。每一步在控制台对 `lab/readme.txt` 执行对应上传/下载动作，别用真实同步数据。

1. **建立可比对的本地基线：**

   ```powershell
   $dir = Join-Path $env:TEMP 'cloudcmd-cos-lab'
   New-Item -ItemType Directory -Path $dir -Force | Out-Null
   $file = Join-Path $dir 'readme.txt'
   Set-Content $file 'cloudcmd-lab-v1' -Encoding utf8
   Get-FileHash $file -Algorithm SHA256
   ```

   **检查：**记下摘要和文件长度，再把该文件上传到 `lab/readme.txt`。控制台对象大小应与本机一致；ETag 不等于 SHA-256，不拿它替代下载校验。
2. **验证私有和短时签名：**用未登录浏览器打开普通对象 URL，应得到拒绝响应；控制台只生成短时签名下载 URL，下载到 `$dir\signed-v1.txt`，执行 `Get-FileHash "$dir\signed-v1.txt" -Algorithm SHA256`。**检查：**两次 SHA-256 相同；过期后链接不可再用。不要把签名 URL 贴进报告。
3. **验证版本恢复：**先在控制台启用桶版本控制，然后执行 `Set-Content $file 'cloudcmd-lab-v2' -Encoding utf8` 并上传覆盖同一 key。下载旧版本到 `$dir\old-v1.txt`，分别 `Get-FileHash $file` 和 `Get-FileHash "$dir\old-v1.txt"`。**检查：**v2 摘要不同，旧版本摘要等于第 1 步；恢复旧版为当前版后再次下载并比较。
4. **验证清理：**在控制台列出该测试桶**所有版本及删除标记**，逐项删除后刷新列表，再删除桶。**检查：**桶不存在、台账已更新；只删除“当前版本”但历史版本还在，不算清理完成。

交付“匿名访问拒绝 → 有时效签名链接可下载 → 旧版本可恢复 → 全版本清理”的证据链，并记录费用和资源 ID。桶仍非空、公开可读或清理后仍有历史版本，都不能算完成。
