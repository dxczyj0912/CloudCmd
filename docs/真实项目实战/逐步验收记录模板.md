# 实战项目逐步验收记录模板

每做一关复制本页到**实验记录仓库**，先写环境和预期，再执行当步命令。失败时停在当前步；解决后记录原因并重做检查，不在最终报告里只写“成功”。本模板是人工证据记录，`tools/real-lab-check.js` 只校验 JSON 清单格式，不会替你连接云资源或判断服务健康。
