# 00 · 云账号、资源清单与成本边界

这是整条路线的第一项**初级云计算项目**：建立一个只用于实验的云资源边界，能回答“资源在哪个账号、区域、网络里，由谁付费、谁有权限删除”。本路线以用户已有的腾讯云账号为例；产品入口以[云服务器](https://cloud.tencent.com/document/product/213)、[访问管理 CAM](https://cloud.tencent.com/document/product/598)和[费用中心](https://cloud.tencent.com/document/product/555)的当前文档为准。还没有云账号时，先完成第 01、02 关，再回来做此项。

## 逐步操作

1. 在控制台核对账号 ID、当前区域、余额与正在运行的实例。只做只读盘点，尤其不要把现有 CloudCmd 网站或同步服务器归入测试资源。
2. 新建一个明确标识为 `cloudcmd-lab` 的实验项目或资源标签。记录项目、区域、负责人、预计使用时长、实例及磁盘计费方式。给实验设置预算提醒；预算提醒是通知，**不是费用硬上限**。
3. 用 CAM 创建仅供实验的身份。先赋予读取实验资源的权限，验证它能列出实验资源、不能创建或删除其他业务资源。后续项目如果要创建资源，只逐项增加该实验项目所需权限；不用主账号长期操作。
4. 建立一份资源台账，列出测试资源 ID、区域、VPC/子网、用途、创建时间、计费方式和预计清理日期。每完成后续项目都更新台账。
5. 在控制台查看实验资源对应的用量与账单明细，确认实例停止、磁盘、快照、对象存储和公网 IP 哪些仍计费。为每种资源写下清理顺序。

## 验收

### 每步留证与停止条件

按控制台当前界面逐项操作；账号、预算和 CAM 页面没有可跨账号照抄的固定资源 ID，因此先记真实值，再进入下一步。以下 PowerShell 只生成**本地实验台账**，不会调用云 API：

```powershell
$labDir = Join-Path $env:TEMP 'cloudcmd-cloud-lab'
New-Item -ItemType Directory -Path $labDir -Force | Out-Null
$ledger = Join-Path $labDir 'resources.csv'
if (Test-Path $ledger) { throw '台账已存在，先检查，不覆盖' }
'project,region,resource_type,resource_id,purpose,created_at,billing,cleanup_by' | Set-Content $ledger -Encoding utf8
Get-Content $ledger
```

1. **账号检查：**登录测试账号，在“账号信息”和“云服务器实例列表”抄下账号、区域和已有资源数量。**确认点：**能把现有 CloudCmd 服务器单独标为生产资源；若账号或区域不确定，停止创建。
2. **成本检查：**在费用中心核对余额、按量价格、预算提醒收件人；先用纸面或本地台账算出“机器 × 小时 + 云盘 + 公网 + 快照”的上限。**确认点：**预算提醒可收到，但明白它不会自动停机。若无法估算，先不购买。
3. **权限检查：**在 CAM 建实验身份，先授只读权限。用该身份登录并尝试查看测试实例列表，再尝试进入创建页但**不要提交创建**。**确认点：**读取成功、无权的业务资源无法修改。若身份权限超出预期，回到 CAM 收紧。
4. **台账检查：**每创建一项资源，立刻追加一行到 `$ledger`，再执行 `Import-Csv $ledger | Format-Table`。**确认点：**每个资源都能按 ID、区域和清理日期找到；没有 ID 的资源不继续做后续项目。
5. **清理检查：**实验结束在控制台按台账逐一释放，重新打开实例、云盘、快照、对象存储和公网 IP 列表核对。**确认点：**台账中的资源 ID 均不再计费；“已停机”不等于“已释放”。

交付脱敏资源台账、预算提醒截图或记录、CAM 只读与拒绝越权的验证证据、费用估算和清理清单。能区分“停止实例”和“释放所有计费资源”，才算完成。不要把账号 ID、密钥和完整账单放进公开仓库。
